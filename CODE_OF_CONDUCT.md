# Code of Conduct

This project follows the
[Everpure Open Connect Code of Conduct](https://github.com/PureStorage-OpenConnect/Code-of-Conduct/blob/main/Open-Source-Contribution-Code-of-Conduct.md),
which applies to every project in the PureStorage-OpenConnect organization.

In short: be patient, welcoming and professional, and do not share personal information about
yourself or anyone else. That includes the hostnames, addresses and account names in the logs,
specs and support bundles you post in issues.

Try to resolve a problem directly first. If you cannot, report it to **legal@everpuredata.com**.
