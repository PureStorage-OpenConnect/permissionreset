# Benchmarks

Summaries of the lab measurements that the docs cite. Each one records the array, client, tree and
method it was taken under; `METHODOLOGY.md` explains the metrics.

Only the summaries are published. Raw captures, per-trial data, run scripts and array metrics stay
in the maintainers' private lab repository, so a summary can name a file (a `trials.tsv`, an
`ab.sh`) that is not here. Lab hosts and arrays appear under neutral names (`client-a`,
`lab array A`) and addresses under the RFC 5737 documentation ranges.
